🍲 Recipe Suggestion System (C++ Project)

This project is a Recipe Suggestion System built in C++ using Linked Lists and File Handling.
It allows users to add, remove, search, and rate recipes while suggesting recipes based on available ingredients.

✨ Features

Ingredient Management

Store ingredients with name, unit, and quantity.

Uses linked lists to manage ingredients dynamically.

Recipe Management

Add, remove, and find recipes.

Rate recipes and update average rating.

Store recipes persistently using file handling (recipes.txt).

Recipe Suggestion

Suggests recipes based on available ingredients entered by the user.

Suggests additional recipes using leftover ingredients.

User Interface

Interactive console interface for input/output.

Prevents negative quantities and invalid ratings.

🛠️ Tech Stack

Language: C++

Concepts Used: OOP (Classes), Linked Lists, File Handling, Recursion (destructors), Dynamic Memory
