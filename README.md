# 🍲 Recipe Suggestion System (C++ Project)

> 🔎 A C++ project that suggests recipes based on the ingredients you have!  
Manage recipes, store them with file handling, and get smart suggestions — all in **command line interface**.

---

## ✨ Features
✅ **Ingredient Management** (Linked List)  
✅ **Recipe Database** with add/remove/search  
✅ **Rating System** (average ratings auto-updated)  
✅ **File Handling** for saving/loading recipes  
✅ **Suggestions** based on available & leftover ingredients  
✅ **User-Friendly Console UI**  

---

## 🛠️ Tech Stack
- **Language**: C++  
- **Concepts Used**:  
  - Object-Oriented Programming  
  - Linked Lists  
  - File Handling  
  - Recursion in Destructors  
  - Dynamic Memory
